# fay

A small cross-platform CLI written in Rust that saves a series of shell commands under one name, so you can replay a whole setup/build/deploy sequence by picking it from a menu instead of retyping it.

![fay](https://user-images.githubusercontent.com/6418354/192144325-97d273db-3d74-4db8-bcec-62d0dfc86c72.gif)

## Features

- **Save a sequence of commands** under a name, run the whole thing with one pick
- **Interactive menu** — no flags to memorise, just run `fay`
- **Works with bash and cmd** — same binary on Windows, macOS and Linux
- **Stored as plain JSON**, so your saved commands are easy to inspect or back up

## Installation

```bash
cargo install fay
```

On [crates.io](https://crates.io/crates/fay).

## How to use

1. Install it with `cargo install fay`
2. Type `fay` and hit enter
3. Follow the CLI instructions — add a command sequence, name it, then pick it from the list to run
4. Enjoy
